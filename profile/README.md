# RepDB

Exercise database, illustrations and looping exercise animations for fitness apps. 700+ exercises with one consistent character, delivered as files you keep: JSON, SQLite, WebP, MP4 and GIF. No API key, no rate limit, no subscription.

## Free

**[exercise-dataset](https://github.com/RepDB/exercise-dataset)**: every exercise as JSON with 512 px illustrations, target muscles, equipment, MET values and instructions in English, German and Spanish. Free in apps, commercial ones included, with a credit to RepDB.

Starter apps built on it:
[Next.js](https://github.com/RepDB/repdb-example-nextjs) ·
[React Native (Expo)](https://github.com/RepDB/repdb-example-react-native) ·
[Flutter](https://github.com/RepDB/repdb-example-flutter)

## Paid

**[repdb.co](https://repdb.co/?utm_source=github-org)**: the same exercises for production, one payment.

- **Standard, $499**: looping animations for 550+ exercises on transparent backgrounds, MP4 and GIF copies, 1024 px stills, a front and back muscle heatmap, SQLite and JSON in four languages. An optional female character covers every exercise.
- **Stills, $299**: the 1024 px stills and JSON, without animations.
