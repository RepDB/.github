# RepDB

Exercise data, illustrations and looping animations for fitness apps: **701 exercises** drawn with one consistent character. You get files you own, so there is no API to call and no rate limit.

## Free

**[exercise-dataset](https://github.com/RepDB/exercise-dataset)** — all 701 exercises as JSON with 512 px illustrations, target muscles, equipment, MET values and instructions in English, German and Spanish. Free in apps, including commercial ones, with attribution.

Starters built on it:
[Next.js](https://github.com/RepDB/repdb-example-nextjs) ·
[React Native (Expo)](https://github.com/RepDB/repdb-example-react-native) ·
[Flutter](https://github.com/RepDB/repdb-example-flutter)

## Paid

**[repdb.co](https://repdb.co/?utm_source=github-org)** — the same exercises as a production library, one payment, no subscription:

- **Standard, $499** — looping animations for 544 exercises on transparent backgrounds, ready-made MP4 and GIF copies, 1024 px stills, a front and back muscle heatmap, SQLite and JSON, four languages. An optional female character covers every exercise.
- **Stills, $299** — the 1024 px stills without animations.
